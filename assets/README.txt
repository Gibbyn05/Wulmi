Image placeholders for Wulmi

Add only the supplied Wulmi artwork here, using these exact filenames:

- logo.png           — sheep-head logo for the header (optional; a W placeholder appears if absent)
- sheep-healthy.png  — healthy sheep artwork used in the hero, concept demo and footer
- sheep-tired.png    — mildly tired sheep artwork (the second state with small stress sweat) used in the concept demo

The website is intentionally designed to keep working if these files are missing: it displays clearly labelled, rounded placeholders instead. Once the files are added, the artwork appears automatically. If an artwork has a baked background, its rounded frame preserves it rather than treating it as transparent.
